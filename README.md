# Data Science & Machine Learning Portfolio

A curated index of applied data-science, machine-learning, statistical-modelling and geospatial projects developed in R and Python.

The portfolio emphasizes reproducible analysis, clear problem framing and practical modelling workflows. Projects range from classical supervised learning and statistical analysis to representation learning, dimensionality reduction and applied healthcare/business analytics.

## Portfolio standards

Repositories are maintained with the following principles:

- clear problem statements and project summaries,
- descriptive file and repository names,
- reproducible dependency information where possible,
- relative rather than machine-specific data paths,
- explicit notes when source data cannot be redistributed,
- separation between exploratory historical work and cleaned reproducible workflows,
- no overstated performance claims or hidden validation leakage.
